# Loyalty+ Store QA Project

## Overview
This repository contains the complete Quality Assurance (QA) work for the **Loyalty+ Store** project, conducted as part of the ICT Upskilling Program – Software Testing and Quality Assurance track at Al Hussein Technical University.

The goal of this project is to validate the functional and technical quality of the Loyalty+ Store platform, including both the web application (SauceDemo) and the backend API (DummyJSON).

---

## Repository Structure
---

## Key Components

1. **Manual Testing**
   - Functional and exploratory test cases
   - Bug reports with severity and priority
   - Test execution screenshots

2. **API Testing**
   - Postman collections (GET, POST, PUT, DELETE)
   - Test data CSV files for data-driven testing
   - Newman automation scripts and reports
   - Performance testing with k6

3. **UI Automation**
   - Selenium WebDriver scripts in JavaScript
   - Automated test scenarios for critical user flows
   - Execution logs and reports

4. **CI/CD & Version Control**
   - GitHub repository with structured branching
   - GitHub Actions for automated execution

---

## Key Findings
- Critical user flows (login, cart, checkout) successfully tested
- Bugs identified, documented, and prioritized
- API and performance testing verified backend reliability
- Automated UI tests improved repeatability and efficiency
